# Правила разметки старотатарских страниц (черновик v0.1)

> Черновик составлен инженером, **должен быть согласован с филологом-тюркологом** до массовой разметки.
> Изменение правил после начала работ = новая версия правил + пометка в истории GT.

Цель разметки — **буквальная (дипломатическая) транскрипция в арабской графике**: что напечатано или написано,
то и набирается. Современная орфография, исправления и перевод — отдельные задачи (Phase 4–5).

## 1. Что размечается на странице

| уровень | что | обязательно |
|---|---|---|
| строка | полигон строки + baseline (линия письма) | да |
| строка | текст строки в арабской графике | да |
| регион | основной текст / заголовок / колонтитул / номер страницы / сноска / маргиналии | желательно (тип региона) |
| порядок | порядок чтения регионов и строк (справа налево, сверху вниз; колонки — справа налево) | да |
| страница | современная кириллица (параллельный текст) | по возможности, отдельным файлом |

## 2. Текст строки

1. **Буквально.** Опечатки оригинала сохраняются. Если нужно исправление — оно пишется в комментарий
   (`{{SIC}}`-аналог), но не в текст строки.
2. **Буквы.** Набирать ту букву, которая видна, а не «правильную»:
   * `ك` vs `ک`, `ي` vs `ی` vs `ى` — по начертанию источника (в иске имля конечная йа без точек → `ی`/`ى` по договорённости проекта: **`ی` U+06CC**);
   * татарские буквы: `ڭ` (U+06AD) или `ݣ` (U+0763) — как напечатано; `گ`, `ۋ`, `چ`, `پ`, `ژ`;
   * яңа имля (1920–1927): `ە`, `ۇ`, `ۆ`, `ۈ`, `ئ`, `ىُ` и спецзнаки (напр. U+08AD `ࢭ`) — как напечатано.
3. **Огласовки, хамза, шадда** — сохранять, если они есть на странице; не добавлять отсутствующие.
4. **ZWNJ (U+200C)** — только где буквы внутри слова видимо не соединены (аффикс отделён без пробела,
   напр. `كتبخانه‌سی`). Пробел — только где на странице есть явный пробел.
5. **Цифры** — в той форме, что напечатана: арабско-индийские `١٢٣` или европейские `123`.
6. **Пунктуация** — как на странице: `،` `؛` `؟` `.` `«»`; знак повтора «〃» набирать как `〃` (U+3003).
7. **Иноязычные вставки** (русский, арабский, персидский) — набирать как есть в их письменности;
   регион/строку можно пометить языком.
8. **Переносы** — не склеивать: одна строка изображения = одна строка текста; знак переноса, если напечатан, сохранить.
9. **Нечитаемое:** `[?]` на месте нечитаемого фрагмента; сомнительное чтение — `[?:вариант]`.
   Такие строки не удаляются, страница получает статус не выше `silver_proofread`.
10. **Не набирать**: декоративные элементы, линейки, орнаменты; колонтитулы и номера страниц размечаются
    отдельными регионами (их можно исключить из обучения распознавания основного текста).

## 3. Статусы и версии

| статус | кто ставит | когда |
|---|---|---|
| `draft_unverified` | машина (`scripts/preannotate.py`) | предразметка; никогда не используется как GT |
| `silver_unproofread` | импорт внешней транскрипции без вычитки | — |
| `silver_proofread` | разметчик | всё проверено по изображению, но есть `[?]` или нет второй проверки |
| `gold_verified` | второй человек (филолог) | независимая проверка, сомнительных мест нет |
| `silver_partial` | любой | транскрипция покрывает не всю страницу (страница не участвует в метриках) |

Каждый импорт создаёт новую неизменяемую версию в `data/gt_history/<page_id>/` (кто, когда, откуда, CER к
предыдущей версии). Старые версии не удаляются и не перезаписываются.

## 4. Рабочий процесс (eScriptorium)

```bash
python scripts/fetch_source_pages.py                         # скачать выбранные страницы источников
python scripts/preannotate.py --batch pilot-01               # черновики PAGE XML + задачи по уверенности
```

1. В eScriptorium: новый документ → загрузить `data/annotation/<batch>/images/*` → *Import → Transcription (XML)* →
   файлы `data/annotation/<batch>/*.xml` (сопоставляются по имени изображения).
2. Исправить полигоны/baseline и порядок строк, затем текст по правилам выше. Начинать со страниц в начале
   `tasks.csv` и строк в начале `lines_to_check.tsv` (наименьшая уверенность модели).
3. Экспорт *PAGE XML* → импорт:

```bash
python scripts/import_annotations.py export/*.xml --status silver_proofread --author "Имя"
python -m benchmark.gt_store log <page_id>                   # история версий страницы
python scripts/export_lines.py                               # строки для обучения (train/val/test по источникам)
```

Без eScriptorium подойдёт любой редактор PAGE XML (Transkribus, PAGE Viewer) — важно сохранить имена файлов.

## 5. Контроль качества

* 10% страниц каждого разметчика размечает второй человек независимо; CER между ними (по профилю `nfc`)
  — оценка согласованности. Цель: < 1% на печати, < 3% на рукописях.
* Расхождения разбираются, правила уточняются в этом документе (с номером версии).
