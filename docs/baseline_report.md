### Исправление данных (важно для всех чисел)
У трёх страниц словаря 1927 г. (13, 15, 225) транскрипция Wikisource покрывает лишь часть страницы
(проверено визуально): из-за этого CER на них был 224–989% — ошибка разметки, а не модели. Они помечены
`silver_partial` в `data/gt_overrides.yaml` (текст GT не изменён) и исключены из подсчёта.
Оцениваемых страниц теперь **42** (core 15, mixed 27).

## Dataset

45 размеченных страниц, 3 источника, только печать (подробно — `docs/dataset.md`):
`ws_tatar_maktabe_1915` (иске имля, 6 стр.), `ws_rus_maktaplare_1925` (яңа имля, 31 стр.),
`ws_tatarcha_uryscha_1927` (яңа имля, двуязычный словарь, 8 стр.). GT — silver (Wikisource, 43 стр. не вычитаны).
Подмножества: `core` 18 стр. (почти чистая арабица), `mixed` 27 стр. (арабица + русский).
Рукописных страниц с GT нет → **handwritten CER: n/a**.

## Models

Подключено 13 бэкендов (`python cli.py models`), из них доступны на машине baseline 11; `tesseract`
(нет системного бинарника) и `transkribus-ottoman` (нет весов, платный API, Print-модель выдаёт латиницу)
зарегистрированы как unavailable. Выбор и лицензии — `docs/model_research.md`.

## Setup

CPU-only (Ryzen Zen 3, 16 потоков, 13.5 GB RAM), Python 3.13, torch 2.11 CPU, kraken 7.1.1, paddleocr 3.7.0.
Предобработка `original` (только EXIF). Kraken: сегментация BLLA, `batch_size=1` (батчинг меняет вывод).
Paddle: детектор по умолчанию, oneDNN выключен. Полный протокол — `docs/experiments.md`.

## Error analysis (предварительно, core 1925)

Частые расхождения (профиль `standard`):
* **пробелы** — главный источник WER у обеих моделей (kraken-ppocrv6: 162 лишних, 81 пропущенный пробел);
  слитное/раздельное написание аффиксов в GT и в модели расходится → WER ≫ CER;
* **знак `ُ` (дамма) в диграфе `ىُ` яңа имля** (= «е/э») теряется: 77 раз у ppocrv6, 125 у paddle;
* `ۇ` (яңа имля «у») читается как `ُ` или `ؤ`; у paddle `چ`→`ج`, `ي`→`ئ`;
* в GT есть спецзнаки яңа имля (напр. U+08AD `ࢭ`), которых нет ни в одном словаре моделей.

Полный разбор по буквам: `python -m evaluation.error_analysis --group core` (после завершения прогонов).

## Recommendation (предварительная)

На 26 общих страницах `kraken-ppocrv6` опережает `paddle` по всем метрикам (core: norm. CER 26.2 против 40.3;
mixed, arabic-only CER: 63.7 против 69.0). Для Phase 2 (предразметка новых страниц для людей) используется
`kraken-ppocrv6`: лучшая из измеренных, Apache-2.0, даёт полигоны строк и baseline (нужны для построчной разметки
в eScriptorium). Выбор модели для **дообучения** (Phase 3) остаётся открытым до прогона CHURRO-3B, Azra и
остальных kraken-моделей.
